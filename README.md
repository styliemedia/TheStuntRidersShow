# The Stunt Riders

Website for The Stunt Riders live stunt show (thestuntridersshow.co.uk).

Plain HTML and CSS, no build step. Hosted on Cloudflare, which redeploys whenever `main` changes.

- `index.html`: content. Anything with `class="todo"` is a gap still to fill (highlighted orange on the page).
- `styles.css`: design, shared with brandonbaily.co.uk
- `assets/`: photos
